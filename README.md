## 简介

放置一个讲台与两颗按钮（召唤 / 送走），模组会：

1. 按你设定的**检测方式**识别村民刷出的附魔书交易；
2. 命中目标就**锁定**，并按需用**铁砧命名**记录价格，然后把村民送走；
3. 未命中就**反复破坏/放置讲台**重刷职业，直到刷出你要的附魔；
4. 背包满了自动**存进箱子**，或用**砂轮把附魔书磨回普通书**（诅咒书单独处理）。

## 安装

1. 安装 Fabric Loader，把 **Fabric API** 与 **maLiLib** 放进 `mods/`；
2. 把 `trade-master-1.0.jar` 放进 `mods/`；
3. 启动游戏。

## 快速上手

1. **搭装置**：讲台 + 召唤按钮 + 送走按钮（可选：箱子若干 / 砂轮 + 铁砧 + 命名牌）；
2. **填坐标**：按 `V` 打开主菜单 →「配置」页 → 先点该行右侧的 `[游戏内选取]` 武装选取，再右键目标方块（或按 maLiLib 的 `P` 键拾取）；
3. **选目标**：「附魔书」页勾选要刷的附魔，设置**等级**与**最高价**；
4. **启动**：热键 `R`，或 `/trademaster start`。

## 装置与坐标

| 坐标项 | 用途 | 必填 | 清空输入框会怎样 |
|---|---|---|---|
| 讲台 | 破坏/放置对象，也是到达判定的基准 | 是 | **不会**被清空（有意保护） |
| 召唤按钮 | 按下后矿车抓取村民 | 是 | 不会 |
| 送走按钮 | 遣返当前村民 | 是 | 不会 |
| 砂轮 | 砂轮模式的目标砂轮 | 否 | **清空 = 关闭砂轮模式** |
| 暂存区原点 + 延伸 | 两个坐标构成方形暂存区（原点 + 正负方向延伸，单位：格） | 否 | 清空任一即视为「不完整」 |
| 暂存区球形半径 | 区域坐标不完整时的回退：以讲台为原点、该半径的球 | 否 | 默认 **8**，范围 1~64 |
| 箱子（可多个） | 背包满时按顺序尝试存放 | 否 | 空文本不清空；用行尾 `[移除]` 删除 |
| 丢弃朝向 yaw/pitch | 砂轮模式下无法入箱的诅咒书的丢弃方向 | 否 | 清空即关闭（运行时按当前值执行） |

**朝向约定**：`yaw` −180=北、−90=东、0=南、90=西；`pitch` 正数朝下（最大 ±90）。
**输入方式**：坐标支持相对坐标 `~`（与目标选择器语义一致）；所有文本输入都是「**失焦或关屏才提交**」，打字中途不会把半截值写进配置。

## 流水线（12 个阶段）

| 阶段 | 做什么 |
|---|---|
| `IDLE` | 未运行 |
| `PRECHECK` | 全局前置检查（坐标 / 启用目标 / 绿宝石 / 书 / 讲台 / 斧头）；背包满则先转存放；按需进入等待 |
| `SUMMON` | 按下召唤按钮，把村民送进装置 |
| `AWAIT_VILLAGER` | 等待村民就位（射线判定点）；处理暂存区等待、婴儿冻结、傻子/不可用村民遣返 |
| `ENSURE_LECTERN` | 确认讲台在位，缺失则副手补放（自愈） |
| `WAIT_PROFESSION` | 等村民转职为图书管理员（可选转职上限） |
| `CHECK_TRADE` | 与村民交互并开启检测通道 |
| `REROLL` | 未命中：按机制破坏讲台重刷职业 |
| `LOCK` | 命中后购买锁定（含买不起时的应急处理） |
| `NAME` | 可选：铁砧命名并记录价格 |
| `SEND_AWAY` | 按下送走按钮遣返村民 |
| `DEPOSIT` | 存放/处理背包里的附魔书（箱子模式或砂轮模式） |

## 重刷机制

| 机制 | 做法 |
|---|---|
| **AXE**（默认） | 主手斧头反复破坏讲台、副手补放；`preventAxeBreaking` 开启时耐久过低拒砍 |
| **TASK_CHAIN** | 破坏讲台 → 等村民失业 → 放置讲台 → 等转职为图书管理员（严格等待职业状态变化） |

两种机制都会**强制切主手斧头**再破坏；放置与交互之间有可配置延时（`placeDelay` / `interactDelay`）。

## 交易检测

| 模式 | 原理 |
|---|---|
| **PACKET** | 拦截 `ClientboundMerchantOffersPacket`，并抑制商人界面闪现 |
| **EVENT** | 容器事件（`initializeContents` + 补货事件），两包齐全（mask == 3）才交付 |
| **BOTH** | 两通道都到齐并**交叉比对**报价；不一致按未命中重试 |

三种模式都带 **3 秒墙钟**与 **containerId 关联**，用于拒绝不属于本次交互的报价包（上一个村民的迟到包、别人打开的商人界面等）。

## 匹配与预算

- 每个**启用**的附魔维护一个「可接受价格」的**最大堆**（价格槽）。
- 一次扫描**全部**报价——数据包/模组可能让一个村民卖多本附魔书，一本书也可能带多个附魔。
- **单附魔书**：成交价 ≤ 该附魔的价格槽。
- **一本书多个附魔 / 一个村民多本合格书**：预算 = 各命中附魔价格槽之和（封顶 **64**），并且只买**最便宜的那本合格书**——因为锁定只需成交一次，村民才是主体。
- **预约更便宜**（`reserveCheaperTraders`）：命中后留下「只接受更便宜」的预约槽。
- **找更便宜**（`huntCheaper`）：锁定后把该附魔标记为「只接受更便宜的副本」；多书村民里**每一本合格书各自记价**；**配置的 `maxPrice` 是这次狩猎的价格上限**（运行中调低立即生效、调高不会放宽），而标记只降不升。
- **互斥规则**：`huntCheaper` 与 `autoDisableAfterLock` **互斥**，同时打开时**以后者优先**；运行中只允许**关闭**找更便宜、不允许开启。
- **资金预算**：`emeraldFloor` = 各启用目标 `maxPrice` 的最大值（至少 `minLockEmeralds`）；开「找更便宜」时抬高到 `maxHuntBudget`；开「单书多附魔保障」时强制 ≥ **64**。

## 锁定

- **购买前二次校验材料**（绿宝石与书）；锁定前校验**指纹**：槽位、价格、**整本附魔集合**必须与检测时完全一致，否则判为漂移 → 免费重刷（宁可重刷也不买错书）。
- **重试上限** `lockMaxRetries`（−1 = 无限重试）。
- **买不起时的处理**：
  - 合格书里**买得起** → 买最便宜的那本；
  - 合格书**全都买不起**，但列表里还有**买得起的其他附魔书** → **应急买下最便宜的那本**以锁定村民（聊天栏黄字提示「这本不是你的目标书」）；
  - **一本都买不起** → 停机报材料不足；若原因是组合书，额外提示可开启「单书多附魔保障」把底线提到 64。
- **锁定成功后记账**：该村民**全部命中目标**都计为已获得 →（若开）自动在配置栏取消这些附魔、（若开）把各自价格写入价格槽、（若开）参与命名。

## 命名

- 需要**铁砧 + 命名牌**（可选功能，默认关闭）。
- 名字格式：`附魔名 罗马数字 价格`（例：`锋利 V 12`）；一本书多附魔用 `+` 连接；一个村民多本书按交易栏顺序列出。
- 支持自定义附魔名；名字里的**数字会转成角标**（⁰¹²³⁴⁵⁶⁷⁸⁹）；自定义名里的 `+` 会转成 `*`（避免与分隔符混淆）。
- 超过铁砧 **50 字符**上限 → **跳过命名**（锁定不受影响）。
- 缺命名牌 / 经验不足 / 命名失败 → 降级为**直接送走**，不影响锁定。
- **命名村民抵扣**：启动/刷新时扫描已命名的图书管理员，把它们已提供的附魔从需求中扣除。

## 存放

### 箱子模式
- **只存附魔书**，不会误存其他物品；
- 多个箱子**依次尝试**，全部塞满则停机；
- 副手书交换有**可配置重试**（`offhandSwapRetries`，−1 = 无限）；重试耗尽走正常停止流程。

### 砂轮模式
- 启用条件（**四要素**）：① `grindstoneEnabled` ② 砂轮坐标 ③ 丢弃朝向 yaw ④ 丢弃朝向 pitch；
- 逐本把附魔书放进砂轮**驱魔**成普通书（每步都等服务端槽位同步，避免延迟导致破坏）；
- **诅咒书**（原版诅咒标签，或你配置的自定义诅咒 id）无法驱魔 → **先塞箱子**，箱子全满则按设定朝向**丢弃**；
- 打开砂轮有可配置重试（`grindstoneOpenRetries`）；
- **运行中修改「启用状态」或「砂轮坐标」→ 按正常流程停止**并提示；**丢弃朝向允许运行中修改**（立即按新值执行）。

## 到达判定与暂存区

- **到达判定**：**单一射线**——玩家 → 讲台 → 再沿射线延伸一格；村民站在该点（约 1.5 格内）才算到位。
- **暂存区**（矿车能抓到的范围）：
  - 区域坐标**完整** → 用「原点 + 延伸」的方形区域；
  - 区域坐标**不完整** → 用「**讲台为原点、半径 `villagerSphereRadius` 的球**」（默认 8）。
- **启动确认**：区域坐标不完整时启动会被**拦截**，提示输入 **`/trademaster goon`** 确认使用球形回退；**其余任何时候该指令无效**（只提示、不做任何事）。确认后自动开始。
- **运行中**：把区域坐标**补全** → 下一次扫描**自动切回**区域；把区域坐标**改成不完整** → **正常停止**并提示。

## 特殊村民处理

| 情况 | 处理 |
|---|---|
| 婴儿村民 | 在**到达点**或**暂存区**出现 → **冻结等待**（不召唤、不遣返、不挑选），直到没有婴儿 |
| 傻子村民（NITWIT） | 在暂存区出现不影响召唤；**到达点**检测到 → 立刻送走 |
| 无业村民 | 可转职为图书管理员 → 正常流程 |
| 其他职业村民 | 在本讲台**永远不会**转职 → 送走 |
| 已命名村民 | 参与命名抵扣（视为已获得其附魔） |

## 防卡死与自愈

- **讲台自愈**：讲台丢失/被破坏后，在宽限期（`lecternHealGrace`，默认 6 秒）内用副手补放。
- **幽灵方块**：客户端以为放置成功但服务端未收到 → 每 tick 校验讲台是否在位，丢失即补。
- **材料预检时机**：启动时、每轮 `PRECHECK`、派发村民前、**每次重刷前**、锁定重试耗尽后。
- **背包满**：先尝试存放；无箱可存或全满则停机（不会把书丢在地上）。
- **歇业等待**：暂存区长期没有村民时处于等待状态，**不算停止**；有村民即继续。
- **超时**：`timeoutEnabled`（默认**关**）为全局看门狗；`phaseTimeoutsEnabled`（默认**开**）为单阶段超时；等待村民阶段豁免。

## 配置入口

三处入口共享**同一份** `config/trade-master.json`：

1. 游戏内主菜单（热键 `V`，触摸屏友好）——四个页签：**附魔书 / 配置 / 键位 / 别名**；
2. **Mod Menu**（提供配置界面入口）；
3. **maLiLib** 配置界面（热键页只在这里）。

> **「别名」页**：给每个附魔起自定义显示名（影响铁砧命名时用的名字）。留空 = 用默认名；**不能与其它附魔的别名或名字重复**（重名会在该行红字提示且不保存）。它只改显示名，不改任何交易条件。

首次启动且本模组配置不存在时，会尝试从原版 **LibrarianTradeFinder** 的 `librarian-trade-finder.json` 迁移**附魔表**与其中 **4 个反作弊开关**（`preventAxeBreaking`、`tpToVillager`、`legitMode`、`slowMode`）；其余开关（`tpToItem`、`stopOnPlayerMove`、`placeDelay`、`interactDelay`）不迁移，使用本模组默认值。

## 兼容性与风险

- **不要**与 LibrarianTradeFinder 同时启用：两者拦截同一批商人封包，会互相干扰。
- clientcommands：仅做「是否加载」探测与共存日志，**不使用其 API**。
- `tpToVillager` / `tpToItem` 在带反作弊的服务器上有被检测风险，默认**关闭**。
- 本模组为**客户端**模组，设计场景是玩家自己的装置 / 单人存档。
